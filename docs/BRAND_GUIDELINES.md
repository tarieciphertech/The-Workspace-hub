# Synexis Technologies — Brand Guidelines

## Core identity
- **Company name:** Synexis Technologies
- **Tagline:** Beyond the Expected.
- **Product name:** Workspace Hub (internal operations product)
- **Brand character:** premium, futuristic, confident, precise, innovative and trustworthy.

## Colour palette
| Token | Hex | Use |
|---|---|---|
| Midnight | `#100817` | Primary background |
| Deep plum | `#17121F` | Secondary background |
| Electric violet | `#8A35E8` | Primary accent and active states |
| Luminous purple | `#B46CFF` | Highlights, focus rings and interactive accents |
| Lavender | `#D8B4FF` | Active navigation and secondary emphasis |
| Silver white | `#F5F0FA` | Headlines and wordmark |
| Muted lilac grey | `#A99AB8` | Secondary text |

## Usage rules
- Use the full name **Synexis Technologies** in company-facing surfaces.
- Use **Workspace Hub** only to describe the internal software product.
- Use the tagline with sentence case and a full stop: **Beyond the Expected.**
- Prefer dark backgrounds, violet gradients, silver-white type and restrained purple glow.
- Keep body text readable; do not use glow effects as a substitute for contrast.
- Do not use Cypher Technologies branding, colours, accounts or infrastructure for this company.
- Avoid stretching, recolouring or recreating the supplied dragon/S emblem inconsistently. Use the approved source artwork when a high-fidelity logo asset is available.

## Current implementation note
The app uses a lightweight typographic “S” mark until the supplied high-resolution logo artwork is added as a repository asset. This keeps the UI branded without embedding a low-resolution screenshot as the logo.
